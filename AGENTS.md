# AGENTS.md for 100 Days of Code Python Project

## Introduction

Welcome to the "100 Days of Code" project. This project is built around learning Python by building various projects each day, inspired by the Udemy course "Master Python by building 100 projects in 100 days." It covers a wide range of Python concepts, including data science, automation, website development, gaming, and app creation.

## Environment Setup

1. **Create Virtual Environment**:
    ```bash
    python3 -m venv path/to/venv
    ```
2. **Activate Virtual Environment**:
    ```bash
    source path/to/venv/bin/activate
    ```

## Project Organization
- `day_1/main.py`: Implements examples of variable assignment with names and pets.
- `packages/users.py`: Contains a dictionary of `usernames` and function `print_name` which works with dictionaries associated with people data.

## Tools and Skills
This project involves a variety of Python tools, libraries, and principles such as:
- Python dictionaries and functions.
- Modular design, showcased in the `packages/` folder.
- Iterative improvement following Python best practices.
